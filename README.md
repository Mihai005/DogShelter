# 🐶 Dog Shelter Management App

## 📜 Description
This Object-Oriented Programming (OOP) project is a **Dog Shelter Management Application** with a **Qt-based GUI**. The app provides two modes: **Admin** and **User**, each with distinct functionalities. It supports multiple repositories, including **CSV and HTML**, for data storage.

## 🚀 Features

### 🔑 Admin Mode
- View all registered dogs.
- **Add / Remove / Update** dogs in the shelter.
- Perform **Undo / Redo** actions.

### 👤 User Mode
- Browse through available dogs **one by one**.
- Choose to **adopt or skip** a dog.
- Filter dogs by **breed and age**.
- View the **adoption list**.
- Export the adoption list as:
  - **HTML webpage** 📄
  - **CSV document** 📜
- View adoption list in a **Qt Table View**.

## 📂 Repositories
- **CSV Repository**: Stores dog data in a CSV file.
- **HTML Repository**: Stores dog data in an HTML file.

## 🖥️ Technologies Used
- **C++** with **Object-Oriented Programming (OOP) principles**.
- **Qt** for GUI implementation.
- **CSV & HTML** for data persistence.

## 🎨 GUI Overview
The app features a user-friendly **Qt-based interface** with separate views for **Admin and User modes**. The user can seamlessly navigate through dogs and adopt their favorites with ease.
